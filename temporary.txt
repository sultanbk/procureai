### **Slide 4: Innovation & Defensibility: "Why Not a Chatbot?"**

*Scores: Innovativeness / Differentiation (15%)*



* **Headline:** Zero-Hallucination Deterministic Engine vs. Generic LLM Wrappers

* **Visual Layout:** Comparison Table:



| Traditional Chat / RAG | ProcureAI Architecture |

| :--- | :--- |

| LLM does math (prone to hallucination) | **Pure Python `Decimal` rule engine**; LLM only extracts |

| Passive: only answers user questions | **Active Reverse Sweep**: detects missed discounts/SLA penalties |

| Treats each invoice in isolation | **Cross-Invoice Drift Analyzer**: catches price creep over time |

| Unstructured text answers | **Structured audit artifacts**, scorecards, & formal dispute letters |



* **Key Talking Points (What to Say - 45s):**

  > *"Judges often ask: why not just prompt ChatGPT or a standard RAG pipeline? The answer is: **Finance teams do not tolerate math hallucinations.** ProcureAI never lets an LLM perform monetary calculations. All calculations execute in a deterministic Python Decimal rule engine. Furthermore, we introduced two industry-first innovations: **Reverse Sweep**, which hunts for credits the supplier 'forgot' to grant, and **Cross-Invoice Drift Detection**, which spots gradual unit-rate inflation across multiple billing cycles."*

3. Have your browser open at `http://localhost:5173/`.

4. Open the demo folder with these ready to drag-and-drop:

   - `data/synthetic/invoices/c001_invoice_i002.pdf`
