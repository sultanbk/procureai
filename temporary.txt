# 🛡️ Part 3: Tough Judge Q&A Defense Sheet

### **Q1: "Why not just write a prompt with ChatGPT or use a standard RAG tool?"**
> **Answer:** *"Standard LLMs fail on two fatal issues in enterprise finance:
> 1. **Math Hallucinations:** Large language models cannot guarantee arithmetic accuracy. ProcureAI enforces a strict Zero-Math Invariant: LLMs only extract and map; 100% of financial math executes in Python using `Decimal` precision.
> 2. **The Amendment Trap:** In standard RAG, when an amendment supersedes an older clause, the vector database retrieves both chunks and either cites the wrong rate or hallucinates. Synapt Context Substrate models documents as a typed Neo4j graph with `SUPERSEDES` relationships, ensuring we always audit against active governing truth."*

### **Q2: "What if the internet or remote Synapt API is offline during deployment?"**
> **Answer:** *"ProcureAI has an automatic **Zero-Fail Fallback**. In `auto` mode, if the remote Trident MCP endpoint is unreachable, our client seamlessly fails over to an embedded in-memory 4-store engine with zero disruption to the user. The UI displays `ACTIVE (EMBEDDED)` so demos and audits never fail."*

### **Q3: "How does this integrate into real enterprise ERP systems (SAP, Oracle, Coupa)?"**
> **Answer:** *"ProcureAI is built as a non-invasive autonomous assurance layer. Invoices can be ingested via standard REST webhooks, EDI, or our background file watcher (`watched_invoices/`), while contracts reside in Context Substrate. Audits run pre-payment (blocking leakage before disbursement) or post-payment (recovery audits)."*

### **Q4: "What prevents prompt injection attacks in vendor invoice PDFs?"**
> **Answer:** *"We implement **6-layer enterprise guardrails**. Layer 1 is an input sanitizer that strips injection preambles and instruction overrides from invoice PDFs before the LLM ever sees them. Layer 2 sanitizes outgoing dispute letters to redact sensitive PII and financial account numbers."*

### **Q5: "How does the system handle multi-currency or different unit metrics?"**
> **Answer:** *"Our `cross_validator` agent includes an automated unit normalizer. It reconciles unit mismatches (such as hours vs. days in consulting, or kg vs. metric tons in logistics) using deterministic conversion factors before compliance calculations begin."*
