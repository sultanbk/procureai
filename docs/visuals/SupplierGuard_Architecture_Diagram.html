Layer 4 — Multi-Agent LangGraph Pipeline (Sequential)
AGENT 1
Contract Parser
IN: contract_text ───────────── 1. Section detection 2. Pricing section filter 3. LLM extraction (JSON) 4. Pydantic validation 5. Retry if invalid ───────────── OUT: ContractRulebook → state[rulebook] ⚠ halt if no rules found
→
AGENT 2
Invoice Extractor
IN: invoice_texts[] + rulebook (context) ───────────── 1. Header extraction 2. Line item extraction 3. Arithmetic validation 4. Semantic mapping 5. Flag low confidence ───────────── OUT: InvoiceData[] → state[invoice_data] ⚠ flag unmapped lines
→
AGENT 3
Compliance Checker
IN: rulebook + invoice_data ───────────── 1. LLM: rule matching 2. rule_engine.py: math 3. Delta computation 4. Severity assignment 5. Evidence assembly 6. Pydantic validation ───────────── OUT: DiscrepancyList → state[discrepancies] ⚠ CORE — most critical
→
AGENT 4
Report Generator
IN: discrepancies ───────────── 1. Aggregate stats 2. Sort by severity 3. Executive summary (LLM) 4. Per-finding narrative 5. Recommendations 6. Pydantic validation 7. DB persist → COMPLETE ───────────── OUT: AuditReport → state[audit_report] → DB + status=COMPLETE
Rule Engine (compliance_checker/rule_engine.py) — Deterministic Python, No LLM
VolumeTierEvaluator
Finds matching tier by quantity, returns tier unit_price × quantity. Uses Decimal.
SLAPenaltyEvaluator
If actual_pct < threshold → credit = invoice_total × penalty_pct. Returns negative (credit owed).
EarlyPaymentEvaluator
If paid within window_days → expected = total × (1 - discount_pct). Else no discount.
FlatRateEvaluator
expected = quantity × flat_unit_price. Simplest evaluator. Baseline for all rate checks.
BundleDiscountEvaluator
Units above bundle_threshold → bundle_price. Units below → standard rate. Split calculation.
CapRateEvaluator
If charged > cap_amount → overcharge = charged − cap. Returns cap_amount as expected.
⚠ CRITICAL RULE: The LLM (Agent 3) identifies WHICH rule applies to WHICH line item.
rule_engine.py computes ALL arithmetic. Financial figures are NEVER computed by an LLM.
All monetary values use Python Decimal — never float.
